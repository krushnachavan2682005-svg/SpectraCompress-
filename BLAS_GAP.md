# Numerical Hardware & BLAS Acceleration Gap Analysis (Day 6)

1. Linear System Acceleration (n=400): Pure-Python Gaussian elimination achieved nominal 0.0200 GFLOPS (2.129 s), whereas np.linalg.solve (OpenBLAS 1T) achieved nominal 24.84 GFLOPS (0.00172 s), yielding an observed gap of 1239x (range across sessions: ~1.2e3 - 3.2e3 depending on CPU load).
2. Scaling Complexity: Empirical local exponent over n=100..400 (3 points, local, noisy) yields n^3.07 for pure-Python vs n^2.10 for LAPACK dgesv (doubling ratios: py=8.21, np=3.38).
3. Overhead Roots (Hypothesis): The baseline gap combines Python bytecode interpretation and boxed object allocation with LAPACK SIMD/FMA vectorization and cache blocking (combined, not isolated).
4. Multithreading Crossover (Hypothesis): Thread synchronization overhead dominates at small sizes (n=400: 1T=1.72 ms vs 4T=4.03 ms; across sessions 4T varied 16.75 ms -> 3.62 ms); crossover where 4T beats 1T is observed at n=1000 (1T=22.55 ms vs 4T=16.39 ms).
5. Locked Decomposition Scaling: On MNIST (8000x784, k=90), sklearn_pca fit took 1.444 s (1T) vs 1.285 s (4T) using svd_solver=full (nominal formula GFLOPS: 20.4).
6. Algorithm Distinction: Apparent 1.80x speedup between scipy svds (0.770 s) and sklearn PCA (1.389 s) at locked k=90 reflects different algorithms, not attributable to sparsity.
7. Locked Subspace Accuracy: At k=90, scipy_implicit_centered and sklearn_pca achieve identical train reconstruction MSE (319322.58) with max principal angle 2.41e-06 deg and mean angle 6.26e-07 deg.
8. Same-Backend Sparsity: scipy_implicit_centered (k=20, not locked config) on CSR vs Dense achieved 2.00x speedup at 1% density and 1.03x at 40% (95% CI: [1.02, 1.04]; no dense crossover observed in tested range).
9. Subprocess Working Set Profile: Sampled current wset max minus pre-fit sample at SAME backend and locked k=90 (scipy_implicit_centered) was 28.9 MB (sparse CSR) vs 101.8 MB (control dense, densified inside measured region); tracemalloc was 27.5 MB vs 95.8 MB. (Dense PCA k=90 wset delta: 160.0 MB, tracemalloc: 215.0 MB; tracemalloc exceeds wset delta due to Python buffer heap high watermark vs OS physical page reuse).
10. Out-of-Core Synthetic Footprint: For synthetic matrix (n=60000, d=20000, nnz=600000, density=0.0005, analytic CSR 7.10 MB, backend=scipy_implicit_centered, matvec_count=327, matrix built before baseline, baseline sample=188.7 MB), analytic dense size is 8.94 GB (exceeding 7.75 GB RAM); measured CSR fit working set delta was only 20.9 MB (never densified).
11. Online Latency: Over 2000 repeats, single-row transform p50 latency is: at d=784 (k=90), sklearn_pca dense = 0.0313 ms vs scipy_implicit_centered CSR = 0.0936 ms; at d=5000 (k=20), dense = 0.0451 ms vs CSR = 0.0800 ms. Dense remains strictly faster for single-row inference at d<=5000 due to contiguous vector registers; no crossover claimed.
